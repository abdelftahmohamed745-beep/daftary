# دفتري — نظام إدارة الدروس والطلبة

تطبيق عربي (RTL) لإدارة مركز دروس: الطلبة والمجموعات والجدول والحضور والاشتراكات والخزنة،
مع امتحانات وتصحيح سريع، شهادات، لوحة شرف، تحليلات، بوابة لأولياء الأمور، كروت طلبة بباركود،
ومزامنة مجلدات ونسخ احتياطي.

## التشغيل

```bash
node server.js
```

- العنوان الافتراضي: `http://localhost:3000` (بيزيد تلقائياً لو البورت مشغول)
- الدخول التجريبي: `admin@daftary.app` / `Daftary@123`
- مساعد: `assistant@daftary.app` / نفس الباسورد

المشروع **بدون أي اعتماديات خارجية** — Node.js 18+ فقط.

## الأوامر

```bash
npm start        # تشغيل السيرفر
npm run dev      # تشغيل مع إعادة تحميل تلقائية
npm test         # اختبار شامل للـ API على قاعدة بيانات مؤقتة
npm run reset    # إعادة بناء البيانات التجريبية
```

## المتغيرات

| المتغير | الوظيفة |
| --- | --- |
| `PORT` | بورت السيرفر |
| `DAFTARY_DATA_DIR` | مسار مجلد البيانات (الافتراضي `data/`) |
| `DAFTARY_DEMO_PASSWORD` | باسورد الحسابات التجريبية |
| `DAFTARY_SECRET` | مفتاح توقيع كوكي الجلسة (مهم على الاستضافة) |
| `DAFTARY_SHOW_CREDENTIALS=0` | إخفاء بيانات الدخول من رسالة التشغيل |

## المزايا

- **لوحة تحكم**: مؤشرات، حصص اليوم، متأخرات، تنبيهات، رسوم بيانية.
- **طلبة ومجموعات**: ملف طالب كامل، تسجيل/إعادة تسجيل، ملاحظات، مستحقات ومدفوعات.
- **جدول وحضور**: تقويم أسبوعي، تحضير سريع، باركود Code39، أرشيف غياب.
- **حسابات وخزنة**: اشتراكات، دفعات، مصروفات، إيصالات، تقارير، تصدير CSV.
- **امتحانات**: إنشاء، تصحيح جماعي، متوسطات ونسب نجاح، تصدير درجات.
- **تميّز**: نقاط، لوحة شرف، شهادات (إفرادي/جماعي)، تحقق عام من الشهادات.
- **تحليلات ذكية**: ملاحظات تلقائية عن التحصيل والحضور والامتحانات.
- **إدارة**: مستخدمون وصلاحيات، إعدادات، نسخ احتياطي، سجل نشاط.
- **ترخيص ومزامنة**: أكواد تفعيل، مزامنة مجلد، سجل مزامنة.
- **بوابة عامة** `/portal.html`: بحث بكود الطالب، شهادات، مراحل ومجموعات.
- **كروت طلبة**: تصميم جاهز للطباعة مع باركود.

## النشر

### Vercel

الرفع جاهز بدون إعدادات إضافية: Vercel بيكتشف `server.js` كمدخل تلقائيًا،
والملفات الساكنة في `public/` بتتخدم مباشرة من الشبكة. قاعدة البيانات التجريبية
بتتبني في `/tmp` عند أول تشغيل لأن مجلد المشروع للقراءة فقط.

```bash
vercel --prod
```

عيّن `DAFTARY_SECRET` في إعدادات المشروع على Vercel قبل النشر حتى يفضل توقيع كوكي
الجلسة ثابت بين النسخ المختلفة (وإلا الجلسة بتنتهي مع كل نسخة جديدة).

> ملاحظة: على Vercel التخزين مؤقت (per-instance)، فأي تعديلات على البيانات تفضل داخل نفس النسخة
> وممكن تتصفّر مع نسخة جديدة. للتشغيل الجاد استخدم سيرفر Node دائم أو قاعدة بيانات خارجية.

## البنية

```
server.js            سيرفر HTTP وموجّه المسارات
lib/                 قاعدة البيانات، المصادقة، الدومين، المزايا، البيانات التجريبية
routes/              وحدات الـ API
public/              واجهة RTL (HTML/CSS/JS بدون build)
public/js/pages/     صفحات الواجهة
scripts/             اختبار الدخان وإعادة بناء البيانات
api/index.js         مدخل Vercel
```

## الاختبار

`npm test` بيشغّل سيرفر مؤقت على قاعدة بيانات منفصلة ويغطي المصادقة، الطلبة، الحضور،
الامتحانات، النقاط، الشهادات، الخزنة، الورديات، الترخيص، المزامنة، الباركود، التصدير،
والبوابة العامة.
